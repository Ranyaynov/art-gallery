# ADR 0003: Choix du Art Institute of Chicago API pour le projet

## Context
Art Gallery est un site gallery qui a besoin d'une base de donnes avec les info sur les art comme une image, un titre, un autheur etc...

## Décision
On choisit Art Institute of Chicago API

## Conséquences 
Positives: 
- Il est public donc gratuit

Négatives:
- On ne peux pas ajouters nos arts
